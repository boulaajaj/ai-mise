# Where your work lives

*This page is written for anyone, with no technical background assumed. It describes how this is meant to work. It is still being built — today only the reading part of it exists — and it is written down first so that what gets built has something to be held to. The reasoning behind it is in [[ADR-0010-where-workspaces-live|ADR-0010]].*

## It's a folder on your computer

Everything the assistant knows about your work sits in one folder on your own computer. You can open it, read it, copy it, back it up, move it, or throw it away. Nobody needs to ask permission, least of all us.

## You can read it without us

The files inside are ordinary text. Open them in any text editor, or any note-taking app, and they make sense — headings, sentences, lists. Nothing is locked in a format only this tool understands.

That is deliberate. If this tool stopped existing tomorrow, everything you had built would still be there, and would still be readable and useful. You are not renting your own work back from us.

## Nothing changes without you seeing it first

Before anything is added or altered, you are shown what would change, in plain words, and asked. If you say no, nothing happens. If you say yes and then change your mind, you can go back to exactly how things were — every version is kept quietly in the background, and you never have to think about it unless you want to.

## If you already have a project, we leave it alone

Point the assistant at work you already have and the first thing it does is read, and only read. It tells you what it found and asks what you would like to do about it.

Everything it adds goes in a single folder tucked inside your project. One folder to look at, one folder to delete if you ever want it gone — and when it's gone, your project is exactly as it was.

If you already have instructions or notes set up for an AI assistant, those are kept. They are read and used, not replaced, unless you specifically ask for that — and even then the originals are kept so you can put them back.

## Nothing leaves your computer unless you ask

No account is required. Nothing is uploaded anywhere. There is no server holding your work.

If you want your work on another computer, copy the folder across. If you want to share it with someone, hand them the folder. It will work for them the same way it works for you.

## If you work with other people

You can choose to share the part of the folder that describes the *work* — how things are done, what has been decided, what the project knows — while what the assistant has learned about *you* stays with you and is not shared.

That split is on purpose. Your colleagues might need the shared understanding of the project. They do not need your notes to yourself.

## The short version

It's yours, it's readable, it's on your machine, nothing moves without you saying so, and you can always go back.
